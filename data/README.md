# Aggregated Tableau Source Data

This folder contains the small aggregated CSV outputs used to build the Tableau dashboard.

The raw NYC 311 source data is not included because the analysis uses 2.32M service requests. The raw public source is queried directly in BigQuery.

- `monthly_operations_metrics.csv` — monthly workload, closures, and resolution-time metrics
- `agency_complaint_performance.csv` — agency and complaint-type performance metrics
- `borough_service_demand.csv` — borough workload and resolution-time metrics
